# Followed Collections

The collections tab shows you all the contracts, wallets, and artists you've followed.

![](<../../../.gitbook/assets/Screenshot 2025-07-12 at 4.36.52 AM.png>)

This page shows:

## Favorite Contracts

Any contract address that you favorite will show up here. It will also show what chain you favorited the contract on.

## Favorite Wallets

Any wallets you favorite will show up here. It will also show what chain it was favorited on.

### ENS Verified

Addresses get a verified checkmark when they have an ENS name attached. For contracts, the strongest checkmark comes from the ENS matching the collection name — but any address with a primary ENS set gets a checkmark either way.

Full details live in [Verified Contracts & Wallets](../verified-contracts-and-wallets.md).
